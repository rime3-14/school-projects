# Flickr Lyon Photo Mining

**INSA Lyon · 4A semester 1 · Data mining team project**

The project maps geotagged photo metadata across Lyon and uses spatial clustering to identify areas of activity. It compares DBSCAN, k-means and hierarchical clustering, then uses tags, titles and capture dates to describe the results.

I built the initial exploration, cleaning, mapping and DBSCAN workflow. The reproducible example uses 640 synthetic records. It produces three interactive maps, temporal reports and a TF-IDF table. The team source and the original dataset are in a private repository.
