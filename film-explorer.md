# DBpedia Film Explorer

**INSA Lyon · 4A semester 1 · Semantic web team project**

The app uses the DBpedia knowledge graph to search for films and find related titles by director, actor, genre, context or period. FastAPI runs SPARQL queries and serves the browser interface.

I worked on the AI-assisted search frontend. The final team integration adds film summaries and guided exploration through an optional language-model gateway. The local application was checked for its homepage, API schema and fallback behavior when the gateway is unavailable. The team source repository is private.
