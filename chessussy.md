# Chessussy

**INSA Lyon · 2A · Python coursework**

A desktop chess prototype with a Tkinter board, drag-and-drop piece movement, timers, captured-piece display and a basic opponent. The board logic represents positions with FEN-style notation and uses per-piece movement rules.

The later coursework version was recovered from the local submission and checked by opening the board and playing a first turn against the opponent. The project is a playable prototype with basic movement rules. The source is in a private repository.
