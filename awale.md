# Awalé Online

**INSA Lyon · 4A semester 1 · Network programming**

Awalé Online is a terminal game for two players over TCP. The server validates moves and synchronizes the board, while the client shows the game and accepts commands. Players can challenge each other, exchange messages and watch a game as spectators.

The final coursework version builds with GCC and Make. A local check connected two clients, accepted a challenge and verified that both received the same turn update after a move. The source repository is private.
